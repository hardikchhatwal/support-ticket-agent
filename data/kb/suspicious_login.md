# Suspicious sign-in alerts and compromised accounts
Category: account

We email you when we see a sign-in from a new device or location.

If the sign-in was you, no action is needed.

If it was not you:
1. Reset your password immediately using "Forgot password" on the sign-in page.
2. Open Settings > Security > Active sessions and click "Sign out all other sessions".
3. Enable two-factor authentication if it is not already on.
4. Revoke and recreate any API keys under Settings > API.

If you can no longer sign in, see data or settings you did not change, see data missing, or see unfamiliar payments, treat it as a security incident: our account security team must investigate, and these cases cannot be resolved with self-service steps.
