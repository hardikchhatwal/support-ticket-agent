# Importing data from CSV or other tools
Category: technical

You can import records from a CSV file or directly from Trello, Asana and Notion.

1. Open Settings > Data & Privacy > Import.
2. Choose CSV or a supported tool. For tools, sign in to authorise read access.
3. For CSV, map each column to a field. The file must be UTF-8 encoded, include a header row, and be under 50 MB.
4. Click "Start import". You will get an email when it finishes.

Rows that fail validation are skipped and listed in a downloadable error report. The most common causes are dates not in YYYY-MM-DD format and non-UTF-8 encoding. Imports can be undone within 24 hours from the Import history page. Imports from tools not listed here are not supported.
